# Whatodo MVP QA 체크리스트

## 환경
- [ ] 모바일 Safari (iOS)
- [ ] 모바일 Chrome (Android)
- [ ] 데스크탑 Chrome
- [ ] 데스크탑 Safari
- [ ] PWA 설치 테스트

## 기능 테스트

### 메인 페이지 (/)
- [ ] GPS 위치 기반 추천 표시
- [ ] 카테고리 필터 작동
- [ ] 장소 카드 클릭 → 상세 페이지 이동
- [ ] 하단 네비게이션 작동

### 지도 (/map)
- [ ] 지마커 표시
- [ ] 장소 선택 시 상세 정보 표시
- [ ] 현재 위치 마커 표시
- [ ] 줌/패닝 작동

### 장소 상세 (/place/[id])
- [ ] 이미지 로딩
- [ ] 영업시간 표시
- [ ] 주소 표시
- [ ] 찜하기/공유 버튼
- [ ] 비슷한 장소 추천

### 찜 목록 (/wishlist)
- [ ] 찜한 장소 표시
- [ ] 찜 해제 작동
- [ ] 비어있을 때 안내 메시지

### 프로필 (/profile)
- [ ] 방문한 장소 수 표시
- [ ] 닉네임 변경
- [ ] 테마 설정

## PWA 테스트
- [ ] 홈 화면에 추가 가능
- [ ] 오프라인 시 기본 페이지 로드
- [ ] 서비스 워커 등록 확인

## 성능
- [ ] LCP < 2.5s
- [ ] CLS < 0.1
- [ ] FID/INP < 200ms
- [ ] Lighthouse 점수 > 80

## 에러 처리
- [ ] 404 페이지
- [ ] 네트워크 오류 시 메시지
- [ ] GPS 권한 거부 처리
