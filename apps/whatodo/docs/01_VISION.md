# 오늘 뭐하지? (Whatodo) — 프로젝트 비전

> 캐나다 워킹홀리데이 한국인을 위한 현지 핫플레이스 발견 플랫폼

---

## 1. 프로젝트 정의

**"오늘 뭐하지?"**는 캐나다에 거주하거나 방문하는 한국인을 대상으로, 현지 맛집·관광·액티비티·카페 등을 지도 기반으로 탐색하고 공유하는 웹 애플리케이션이다. 단순한 장소 검색을 넘어 찜·방문·리뷰·태그·컬렉션·게이미피케이션 등 개인화된 경험과 소셜 기능을 통해 사용자 참여를 극대화한다.

---

## 2. 시장 필요성 (Problem Statement)

### 2.1 타겟 사용자 페인포인트

캐나다 워킹홀리데이(WHV) 및 유학생, 여행자 한국인들은 다음과 같은 어려움을 겪는다:

| 페인포인트 | 기존 해결책의 한계 |
|-----------|------------------|
| **정보 파편화** | 네이버 블로그, 인스타그램, 구글맵 등 여러 플랫폼에 정보가 분산되어 있어 통합 검색 불가 |
| **언어 장벽** | 구글 리뷰/영문 사이트는 한국인 입맛/문화적 맥락을 반영하지 못함 |
| **위치 기반 탐색 부재** | 대부분의 한국어 정보는 텍스트 중심으로 지도와 연동되지 않음 |
| **신뢰성** | 블로그 후기의 상업적 광고 성향으로 인해 정보의 객관성 저하 |
| **커뮤니티 부재** | 같은 지역에 있는 한국인끼리 실시간 정보 공유가 어려움 |

### 2.2 시장 규모

- **캐나다 한인 인구**: 약 22만 명 (2024 기준), 연 3~5% 성장
- **캐나다 워킹홀리데이**: 연평균 4,000~6,000명 (한국 출발 기준)
- **캐나다 유학생**: 약 3만 명 (한국 출신)
- **TAM (Total Addressable Market)**: 캐나다 내 한국인 및 한국어 사용자 약 30만 명
- **SAM (Serviceable Available Market)**: 디지털에 능숙한 20~30대 한국인 약 15만 명
- **SOM (Serviceable Obtainable Market)**: 초기 타겟 — 토론토·밴쿠버·몬트리올 중심 약 5만 명

## 3. 프로젝트 비전 (Vision)

> **"캐나다 한인의 첫 발걸음이 되는 현지 생활 가이드 플랫폼"**

### 핵심 가치

1. **신뢰 (Trustworthiness)** — 한국인 커뮤니티의 실제 방문 기록과 리뷰 기반 데이터
2. **편의 (Convenience)** — 지도 기반 실시간 탐색 + 개인화된 저장/관리
3. **연결 (Connection)** — 비슷한 취향의 사용자들과 장소 공유 및 소통
4. **재미 (Fun)** — 게이미피케이션으로 탐험 동기 부여

## 4. 경쟁 분석 (Competitive Landscape)

| 경쟁사 | 장점 | 단점 | 차별화 포인트 |
|--------|------|------|--------------|
| **Google Maps** | 방대한 DB, 신뢰도 | 한국인 취향/맥락 부재, 리뷰 품질 저하 | 한국인 특화 태그, 실제 방문 인증 |
| **네이버 블로그/지식인** | 한국어 정보 풍부 | 비구조화, 검색 어려움, 광고 혼재 | 구조화된 데이터, 지도 연동 |
| **TripAdvisor** | 여행 정보 전문 | 워홀/이민자 생활 정보 부재 | 장기 거주자 중심의 생활 밀착형 정보 |
| **Yelp** | 현지인 기준 평가 | 한국인 입맥/문화 반영 안 됨 | 한국인 특화 필터링 |
| **인스타그램/틱톡** | 트렌디, 시각적 | 검색/조직화 불가, 지도 부재 | 체계적 탐색 + 개인화 관리 |

## 6. 핵심 가치 제안 (UVP)

> **"캐나다에서 오늘 뭐할지 고민될 땐, 지도 위에서 바로 찾고, 저장하고, 공유하세요. 한국인이 인증한 진짜 핫플."**

1. **한국인 특화** — 언어, 입맛, 문화적 맥락을 반영한 장소 선별
2. **지도 중심 탐색** — 위치 기반 실시간 탐색, 근처 핫플 즉시 발견
3. **개인화 경험** — 찜, 방문, 리뷰, 태그, 컬렉션으로 나만의 캐나다 지도 완성
4. **커뮤니티 기반 신뢰** — 실제 방문 인증과 리뷰로 검증된 정보
