# 시장 접근 & 성장 전략

## 1. Go-to-Market 전략

### 1.1 시드 유저 확보 (0 → 1,000명)

| 전략 | 채널 | 예상 효과 |
|------|------|----------|
| **커뮤니티 잠입** | 토론토/밴쿠버 한인 카톡 오픈채팅 | 200명 |
| **인플루언어 마케팅** | 워홀 브이로그/인스타그램 계정 콜라보 | 300명 |
| **워홀 에이전시** | 출국 전 세미나 자료 및 QR 배포 | 200명 |
| **대학 한인학생회** | UofT, UBC, SFU 등 학생회 포스터/공유 | 150명 |
| **구글 검색** | SEO 최적화 장소 페이지 (SSG) | 150명 |

### 1.2 성장 엔진 (1,000 → 10,000명)

- **바이럴 루프**: 장소 공유 → 친구 유입 → 활동 → 공유
- **리뷰 챌린지**: 리뷰 5개 작성 시 배지 + 포인트 2배 이벤트
- **지역 오프라인 이벤트**: "토론토 한인 핫플 투어" 월 1회 주최

### 1.3 확장 (10,000명 ~)

- **도시 확장**: 캘거리 → 에드먼턴 → 오타와 순차 확장
- **국가 확장**: 미국(시애틀, 뉴욕), 호주(시드니, 멜버른), 영국
- **B2B 파트너십**: 워홀 에이전시, 유학원, 현지 한인 업체

## 2. 마케팅 전략

### 2.1 콘텐츠 마케팅

| 콘텐츠 유형 | 빈도 | 채널 |
|------------|------|------|
| **주간 핫플 추천** | 주 1회 | 인스타그램, 카톡 |
| **신규 장소 알림** | 실시간 | 푸시 알림 |
| **워홀 가이드** | 월 1회 | 블로그 (SEO) |
| **사용자 스토리** | 월 2회 | 인스타그램 |

### 2.2 검색 최적화 (SEO)

- `/place/[id]` 페이지는 SSG로 생성되어 구글 인덱싱 대상
- 메타 태그 (OG, description) 최적화
- "토론토 한인 맛집", "밴쿠버 워홀 추천" 등 한국어 키워드 타겟팅

## 3. 사용자 참여 (Engagement) 전략

| 전략 | 설명 |
|------|------|
| **게이미피케이션** | 포인트/레벨/배지/룰렛으로 탐험 동기 부여 |
| **주간 미션** | "이번 주 3곳 방문하고 리뷰 쓰기" 등 주기적 과제 |
| **리더보드** | 지역별 방문 순위 (익명화) |
| **친구 기능** | 방문한 곳 공유, 추천 교환 |

## 4. 리텐션 전략

| 전략 | 설명 |
|------|------|
| **온보딩 투어** | 4단계로 핵심 기능 안내 |

## 5. 위험 관리

| 리스크 | 대응 전략 |
|--------|----------|
| 데이터 신뢰성 저하 | 사용자 리뷰 + 방문 인증 체계 강화 |
