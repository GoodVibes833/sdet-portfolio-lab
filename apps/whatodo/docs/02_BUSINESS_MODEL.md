# 비즈니스 모델 & 수익화 전략

## 1. 비즈니스 모델 캔버스

| 요소 | 내용 |
|------|------|
| **고객 세그먼트** | 캐나다 워홀러, 유학생,短期 여행자, 이민 1~3년 차 |
| **가치 제안** | 한국인 입맛/문화 기반 현지 핫플 발견 및 관리 |
| **채널** | 웹앱(PWA), 인스타그램, 카카오톡 오픈채팅 |
| **고객 관계** | 커뮤니티 리뷰, 게이미피케이션, 푸시 알림 |
| **수익원** | 프리미엄 구독, 지역 업체 광고, 제휴 커미션 |
| **핵심 자원** | 장소 데이터베이스, 사용자 리뷰 데이터, 커뮤니티 |
| **핵심 활동** | 데이터 수집/큐레이션, 플랫폼 운영, 커뮤니티 관리 |
| **파트너십** | 현지 한인 업체, 여행사, 워홀 에이전시 |
| **비용 구조** | 서버비(Vercel 무료티어), 데이터 수집, 마케팅 |

## 2. 수익화 로드맵

### Phase 1: 성장 (현재 ~ 6개월) — 무료
- 모든 기능 무료 제공
- 사용자 기반 확대에 집중
- 데이터 축적

### Phase 2: 프리미엄 (6~12개월)
| 기능 | Free | Premium |
|------|------|---------|
| 장소 검색/지도 | O | O |
| 찜/방문/리뷰 | O | O |
| 컬렉션 | 최대 3개 | 무제한 |
| 필터 프리셋 | 최대 3개 | 무제한 |
| 광고 노출 | O | X |
| AI 추천 | X | O |
| 오프라인 지도 | X | O |

**예상 가격**: CA$4.99/월 또는 CA$39.99/년

### Phase 3: B2B (12개월 ~)
- **지역 업체 광고**: 한인 식당/카페의 노출 광고 (CA$99/월)
- **제휴 커미션**: 예약/배달 앱 연계 수수료
- **데이터 리포트**: 지역 상권 분석 데이터 판매

## 3. 고객 획득 전략 (CAC)

| 채널 | 전략 | 예상 CAC |
|------|------|---------|
| **카카오톡 오픈채팅** | 토론토/밴쿠버 한인 커뮤니티 자연스러운 공유 | CA$0.5 |
| **인스타그램** | 핫플 레이아웃 이미지 + 해시태그 마케팅 | CA$2 |
| **워홀 에이전시** | 출국 전 오리엔테이션 자료 제공 | CA$1 |
| **구글 애드워즈** | "캐나다 토론토 맛집" 등 한국어 키워드 | CA$5 |
| **오가닉 (SEO)** | 블로그 콘텐츠 + 장소 상세 페이지 | CA$0 |

## 4. 생존 지표 (Unit Economics)

- **LTV/CAC 목표**: 3:1 이상
- **월 고정비용**: CA$50 (도메인 + Vercel Pro 예상)
- **손익분기점**: Premium 11명 또는 광고 1건
