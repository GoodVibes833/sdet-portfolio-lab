# 주요 기능 상세

## Phase 1: 사용자 데이터 관리 (Core UX)

| 기능 | 설명 | 기술 |
|------|------|------|
| **찜 (Favorites)** | 하트 클릭으로 장소 저장 | localStorage `favorites` |
| **방문 체크 (Visited)** | 방문 여부 + 타임스탬프 기록 | localStorage `visited` |
| **리뷰 (Reviews)** | 장소별 텍스트 리뷰 작성 | localStorage `reviews` |
| **메모 (Memos)** | 개인 참고용 메모 | localStorage `memos` |
| **태그 (Tags)** | 사용자 정의 태그 분류 | localStorage `tags` |
| **컬렉션 (Collections)** | 장소를 폴더별로 그룹화 | localStorage `collections` |

## Phase 2: 검색 & 필터 고급

| 기능 | 설명 |
|------|------|
| **검색 자동완성** | 실시간 제안 + 하이라이트 |
| **카테고리 필터** | 맛집/관광/액티비티/쇼핑/자연/야경/카페/스포츠 |
| **반경 필터** | 1km ~ 50km 현재 위치 기반 |
| **정렬** | 거리순/평점순/리뷰순 |
| **필터 프리셋** | 자주 쓰는 필터 조합 저장/불러오기 |

## Phase 3: 지도 & 위치

| 기능 | 설명 |
|------|------|
| **거리 측정** | 클릭으로 지도 위 거리 측정 (Haversine) |
| **인근 장소** | 현재 위치 반경 내 핫플 표시 |
| **GPS 트래킹** | 실시간 사용자 위치 파란 점 표시 |

## Phase 4: 장소 상세 고급

| 기능 | 설명 |
|------|------|
| **전화 걸기** | `tel:` 링크 |
| **이미지 라이트박스** | 클릭 시 전체 화면 확대 |
| **유사 장소 추천** | 같은 카테고리/근처 장소 |
| **영업시간** | (데이터 확장 시) |

## Phase 5: 공유 & 소셜

| 기능 | 설명 |
|------|------|
| **QR 코드** | 장소 URL QR 생성 |
| **공유 템플릿** | 이름/주소/URL 포맷된 텍스트 |
| **네이버 공유** | 블로그/카페 공유 링크 |
| **OG 태그** | SNS 공유 시 미리보기 메타데이터 |
| **투표 (Poll)** | 장소 간 투표 UI |

## Phase 6: 게이미피케이션

| 기능 | 설명 | 보상 |
|------|------|------|
| **포인트** | 행동별 포인트 적립 | — |
| **레벨** | 포인트 누적로 레벨업 | Lv.1 Explorer → Lv.10 Master |

## Phase 7: UI/테마 고급

| 기능 | 설명 |
|------|------|
| **온보딩 투어** | 4단계 신규 사용자 가이드 |
| **폰트 설정** | Sans-serif / Serif / Monospace |
